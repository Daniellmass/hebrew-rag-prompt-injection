Detection and Analysis of Prompt Injection Attacks

Prompt Injection Attacks in Hebrew RAG Systems

Technical Report

This project investigates prompt injection attacks in Retrieval-Augmented Generation systems operating on Hebrew legal documents.

The project includes data preparation, Hebrew document chunking, vector retrieval using FAISS, language-model evaluation, and experiments involving several prompt injection attack types.
