# Data

The datasets used in this project are **not included** in this repository.

## Dataset

The experiments were conducted on a cleaned subset of publicly available Israeli Supreme Court rulings.

## Why is the data not included?

The original dataset is omitted to keep the repository lightweight and because the data can be obtained directly from its original source.

## Reproducing the Experiments

1. Download the original dataset from its official source.
2. Place the downloaded files inside the `data/` directory.
3. Run the notebook to perform preprocessing, chunking, indexing, and evaluation.

After downloading, the directory structure should look like:

```text
data/
├── raw/
├── processed/
└── ...
```

Refer to the notebook for the complete preprocessing pipeline.
